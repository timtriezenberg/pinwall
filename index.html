Import from Milanote

Milanote exports text and images separately, so bring both. Card text, to-do lists, links, images and sub-board sections come across; exact card positions, arrows and card colors don't survive Milanote's export, so cards get laid out in a tidy grid.

  1. In Milanote, open the board and choose Export → Markdown.
  2. Then Export → Generate ZIP for the images and files.
  3. Drop both files below. Repeat per board, or drop several Markdown files at once.
  4. Moving from the Claude version of Pinwall? Use its Export → Backup (.json) and drop that file here.
